## Overview

SAYANA Studio is a software and web development studio based in Phnom Penh. This project was a design-focused landing page built in Framer.

## Implementation

I focused on the visual direction, page structure, interaction rhythm, and presentation of the studio's services, team, and featured work.

## Lessons Learned

Landing pages work best when visual energy supports a clear story instead of competing with it.
